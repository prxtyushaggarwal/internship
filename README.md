# VerifyIntern · Is This Internship Real?
### A Design Thinking Web Application (INT335 · LPU · Project P24)

This repository contains the interactive solution designed to solve the design thinking challenge: **"How can students judge quickly whether an off-campus internship opportunity is real and worth it?"**

---

## 📂 Project Structure

- **[`index.html`](file:///C:/Users/pratyush/.gemini/antigravity/scratch/internship-real-design-thinking/index.html)**: **The Live Solution Web Application (VerifyIntern)**
  - **Listing Analyzer & Rule Engine**: Paste any internship text or recruiter message to detect fee scams, ghost tasks, and fake domains. Calculates an interactive Risk Score (0–100%) and explains the rationale.
  - **Verification Walkthrough**: Direct 4-step protocol covering MCA entity lookups, LinkedIn employee audits, WHOIS domain age checks, and take-home labor boundary tests.
  - **Senior Experience Bank & Scam Tracker**: Searchable repository of anonymized peer reports, scam alerts, and verified genuine roles.
  - **Recruiter Response Templates**: Assertive, copy-ready email/WhatsApp response scripts to decline upfront fee demands, request official entity CINs, or set boundaries on excessive unpaid work.
  - **Community Incident Reporting Form**: Allows students to submit anonymous reports to alert peers.
  - **Safe Limits & T&P Escalation**: Highlights that the tool provides decision support, not an absolute guarantee.

- **[`presentation.html`](file:///C:/Users/pratyush/.gemini/antigravity/scratch/internship-real-design-thinking/presentation.html)**: **12-Slide Academic Presentation Deck**
  - Clean fullscreen slide deck covering slides P24/01 to P24/12 with keyboard navigation (`←` / `→`).
